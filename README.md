# Páginas públicas do Hora Boa (ADR-053)

Fonte do site estático publicado no GitHub Pages (repositório público `FabioRenno/hora-boa-site`, só com estes arquivos). Esta pasta é a fonte única; o repositório público é uma cópia para publicação.

- `index.html`, `privacidade/`, `termos/`, `excluir-conta/` e `style.css`: sem JavaScript, sem cookies e sem recursos externos.
- Trocar o e-mail de suporte: procurar `class="pendente"` em todos os arquivos.
- Publicar: copiar os arquivos desta pasta para um clone de `hora-boa-site`, conferir que não há nada além deles e fazer `git push` na `main`.
- Os textos são rascunho. A revisão jurídica de um profissional é obrigatória antes de abrir o app ao público.
